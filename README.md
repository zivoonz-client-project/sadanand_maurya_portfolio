## 🌟 Key Features

- **🎨 Warm Cream, Pure White & Royal Blue Design System:**
  - Soft warm cream ivory backdrop (`#faf8f5` / `#f4efe6`) that provides a soothing, high-end editorial feel.
  - Crisp pure white cards (`#ffffff`) with subtle warm borders (`#e8e2d8`) and elevation shadows.
  - Vibrant Royal Blue (`#2563eb`) & Sky Blue (`#0284c7`) accent gradients and interactive states.
- **🌌 Interactive 3D Canvas Physics:**
  - Dependency-free 3D particle constellation canvas with dynamic camera parallax, depth-scaling, and ambient aurora glows.
- **📱 Realistic Smartphone Device Showcase:**
  - 3D tilted smartphone chassis with hardware side-buttons, selfie camera punch hole, and Android system status bar highlighting the upcoming **MyDigi** smart warranty vault app.
- **🚀 Featured Play Store & Client Deployments:**
  - Highlighting live production Android applications on Google Play (**UdharKhata**, ShopNest, BestInCity, JHATPAT) and solo client websites (**Siddhivinayak Recovery**, **KP Industries**, **Fiscora**).
- **🧲 Micro-Interactions & Fluid Motion:**
  - Framer Motion 3D perspective tilts, magnetic cursor pull buttons, typewriter headlines, dynamic role rotator, and animated KPI metrics.
- **⚡ Blazing Fast Performance & SEO:**
  - Zero-layout-shift (CLS = 0), semantic HTML5, automated OpenGraph meta tags, and full accessibility (`prefers-reduced-motion` compliance).

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (version `18.17` or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) or [pnpm](https://pnpm.io/)

### 1. Clone the Repository

```bash
git clone https://github.com/SadanandMaurya1622/sadanand_maurya_portfolio.git
cd sadanand_maurya_portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Production Build

To build and test the production bundle:

```bash
npm run build
npm start
```

## ☁️ Deployment

### Deploy to Vercel (Recommended)

1. Push your code to your GitHub repository.
2. Visit [Vercel](https://vercel.com/) and click **Add New** → **Project**.
3. Import the `sadanand_maurya_portfolio` repository.
4. Keep all build defaults (`Next.js` is automatically detected).
5. Click **Deploy**.

No custom environment variables are required.
